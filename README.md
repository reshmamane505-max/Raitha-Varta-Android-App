# 🌾 Raitha Varta – AI Powered Agriculture Advisory App

## 📌 Project Overview

Raitha Varta is an AI-powered agriculture advisory Android application designed to provide farmers with short, practical, and easy-to-understand farming guidance through daily flash-card style updates. The application delivers crop-specific recommendations based on weather conditions, soil information, seasonal farming practices, and expert agricultural insights.

The project focuses on improving farmer awareness, decision-making, and accessibility to smart farming knowledge through a simple, scalable, and user-friendly mobile platform.

---

## 🚀 Features

* 🌱 AI-powered agriculture recommendations
* 📅 Daily farming flash-card updates
* ☁️ Weather-based crop suggestions
* 🌾 Crop-specific farming guidance
* 🧠 Google Gemini AI integration
* 📱 Modern Android UI using Jetpack Compose
* 🔥 Firebase backend integration
* 💾 Offline storage using Room Database
* ⚡ Scalable MVVM architecture
* 🔐 Secure and optimized app performance

## ⚙️ Installation Steps

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/reshmamane505-max/Raitha-Varta-Android-App.git
```

### 2️⃣ Open in Android Studio

* Open Android Studio
* Click on **Open Project**
* Select the project folder

### 3️⃣ Sync Gradle

Allow Gradle dependencies to download completely.

### 4️⃣ Run the Application

* Connect Android device or emulator
* Click ▶ Run
